# DT Vocabulary Guidelines

You cannot memorize a full dictionary. When you write or change text, obey these primary vocabulary rules. Refer to the list of frequent errors that follows.

DT is based on the ASD-STE100 Simplified Technical standard, but it is a reduced version. It includes changes for software documentation. It is not the official ASD-STE100 standard.

## 1. Core Vocabulary Rules

### One Word, One Meaning

Approved words have specified meanings. Do not use an approved word with a meaning that is not approved.

Example: `Follow` means `come after.` It does not mean `obey.`

Non-DT: "Follow the instructions."
DT: "Obey the instructions."

### Approved Parts of Speech

Words frequently have more than one part of speech. In DT, you must use a word only as its approved part of speech.

Example: `Damage` is a noun, not a verb.
Non-DT: "Do not damage the server."
DT: "Make sure that you do not cause damage to the server."

Example: `Test` is a noun, not a verb.
Non-DT: "Test the software."
DT: "Do a test of the software."

Example: `Work` is a noun, not a verb.
Non-DT: "When you work..."
DT: "When you do work..."

### No Phrasal Verbs

Do not put a verb and a preposition together to make a phrasal verb.
Non-DT: "Put out the fire."
DT: "Extinguish the fire."

### No Latin Abbreviations

Do not use `e.g.`, `i.e.`, or `etc.`

Non-DT: "Discard standard parts (e.g., `washers`)".
DT: "Discard standard parts (for example, `washers`)".

## 2. Words That Are Not Approved

Do not use a word that is not approved. Use an approved alternative if it has the same part of speech. If it does not have the same part of speech, use a different sentence construction.

Word-for-word replacement: `Acceptable` becomes `Permitted`.
Different sentence construction: `Operable` (adjective, not approved) becomes `Operate` (verb, approved).

Non-DT: Make sure the valve is operable.
DT: Make sure that the valve can operate.

## 3. Frequent Vocabulary Replacements

When you write or change text, always use these approved alternatives.

| avoid | PREVENT | `Turn slowly to prevent damage.` |

| carry out / perform | DO | `Do the leak test.` |
| check (verb) | CHECK (noun) | `Do a check of the system.` |
| damage (verb) | DAMAGE (noun) | `Do not cause damage to the unit.` |
| ensure / make certain | MAKE SURE | `Make sure that the valve is open.` |
| fit (verb) | INSTALL / ATTACH | `Install the duct.` |
| follow (instructions) | OBEY | `Obey the safety precautions.` |
| however | BUT | `...But the procedure will decrease the time.` |

## 4. Technical Nouns and Verbs

You can use technical nouns and technical verbs that are not in the primary dictionary. These words must be in an approved category.

### Software and IT Examples

Nouns: `database`, `server`, `firewall`, `software`, `backup`, `operating system`, `network`, `laptop`.

Verbs: `click`, `download`, `reboot`, `format`, `scroll`, `compile`, `install`.

### Hardware and Mechanical Examples

Nouns: `actuator`, `grease`, `fuselage`, `landing gear`, `engine`.

Verbs: `ream`, `drill`, `weld`, `lubricate`.

### Rule for Consistency

When you select a technical noun (for example, `server`), do not use a different technical noun (for example, `remote host`) for the same item. Always use a consistent style.
